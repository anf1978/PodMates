# Recovered scripts (record only, never run)

These files are copied **word for word** from the saved record of the Claude chat session that did the
Nov 3, 2026 baseline refit ([Product Bible](../../../docs/history/product-bible-2026-11-10.md) Pass 42). The session's working folder was lost, and the owner recovered
them on Nov 12, 2026. They were written for the old single-file `index.html` (paths such as `/home/claude/` and
globals such as `TRY_A_DECK_OPTIONS`, `analyzeOneList`), so none of them runs against today's code. Lint skips
this folder on purpose. Don't edit them: their value is that they are exactly what ran.

| File                                  | What it was                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `inline-python-patches-and-calcs.txt` | 14 inline shell/Python snippets from that session. **Script 7** built `STAPLES_BASELINE` and `MANABASE_BASELINE`; it is ported in [`../benchmark-baselines.mjs`](../benchmark-baselines.mjs), which reproduced the Nov 3 files byte for byte (020; refit over all samples in 034). Scripts 1–5 fitted the Commander Centrality support medians and bands (now constants in `src/engine/centrality-rules.ts`). Scripts 6 and 8–13 are one-off edits to the old `index.html`, already part of today's code. |
| `pw170.cjs`                           | Headless-browser run of the old page: Commander Centrality for every sample deck, written to `cen174.json` (input to scripts 2–5).                                                                                                                                                                                                                                                                                                                                        |
| `txt.py`                              | Rewrote the Deck Chart explainer texts in the old `index.html` (now in `src/features/deck-chart/explainers/`).                                                                                                                                                                                                                                                                                                                                                            |
| `pwja.cjs`                            | Browser check of the Japanese translation hint banner.                                                                                                                                                                                                                                                                                                                                                                                                                    |

Still **not** recovered: `pw160.cjs` (it wrote `feat174.json`, the per-deck input to script 7; rebuilt from the
engine in `benchmark-baselines.mjs`), `know-build.cjs` (`KNOW_JSON`), `impact-cands.cjs` (`IMPACT_CANDS`), and
the builders of `REFERENCE_SCORES` and `REFERENCE_TIERS`. `PRECON_FINGERPRINTS` needed no separate script (the
engine's `buildFingerprintVector()`); since change 034 `benchmark-baselines.mjs` builds it too.
